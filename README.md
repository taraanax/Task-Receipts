# Task Receipts

A tiny **productivity app** inspired by retro pagers and thermal receipt printers.
<br>I wanted to build something that makes finishing a task feel _satisfying_.
<br>Task Receipts turns every completed task into a tiny printed memory instead of another disappearing checkbox.

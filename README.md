# Task Receipts

A tiny productivity app inspired by retro pagers and thermal receipt printers.

| **Project** | **Live Demo** |
|:----------- |:------------- |
| Retro-inspired productivity timer that prints a receipt for every completed task. | https://taraanax.github.io/Task-Receipts/ |


| **Features** | **Built With** |  |
|:------------ |:-------------- |:----------------:|
| • Retro pager timer<br>• Thermal receipt generator<br>• Session summary<br>• Ongoing / Done tasks<br>• Light & Dark mode<br>• Local storage | • HTML<br>• CSS<br>• Vanilla JavaScript | |
## Running Locally

```bash
git clone https://github.com/taraanax/Task-Receipts.git
```

Open `index.html` with Live Server.
